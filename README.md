# npmjs-chinese

将 npmjs.com 网页翻译为中文

## 支持的脚本管理器

已测试油猴和油猴测试版，其他的不确保可用，请自行测试

## 安装方式

- [点击此处安装`最新稳定版`](https://github.com/th-dd/npmjs-chinese/raw/refs/heads/master/master.user.js)

- [点击此处安装`开发测试版`](https://github.com/th-dd/npmjs-chinese/raw/refs/heads/dev/master.user.js)

> 对于`开发测试版`，如果你是想体验最新的词库，安装好脚本后请手动修改脚本的`require` 为：`https://raw.githubusercontent.com/th-dd/npmjs-chinese/dev/i18n.js`
